PAC-MAN
=======

Run
---
Start the `pac-man` executable. It uses the `config.json` file in this folder.

Controls
--------
- Arrow keys or W/A/S/D: move Pac-Man
- Escape: pause/resume; return to the main menu
- E: show/hide the ghost target overlay (review/debug aid)
- Q: add a life (review/debug aid)
- T: add time (review/debug aid)
- Mouse: select menu buttons

Configuration and saves
-----------------------
`config.json` controls maze size, lives, score values, seeds, and the level
time limit. `scores.json` stores the local top-ten highscore table. Keep both
files next to the executable.

Requirements
------------
This Linux x86_64 build requires a desktop session with graphics and audio
drivers. No Python installation is needed.
